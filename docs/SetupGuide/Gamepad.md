# Gamepad Controls

You can control your Switch using a USB or Bluetooth gamepad connected to your computer.

## Using a gamepad

1. Connect a gamepad.
2. Click the console's video display to activate its controls, as you would for keyboard input.
3. Release all buttons, triggers, and sticks.
4. Start playing.

The first available gamepad is selected automatically. To use another, disconnect the selected gamepad. Discovery can take up to one second, and disconnecting a gamepad releases its controls.

Gamepad input follows the same input locks as keyboard control. After changing focus, switching consoles, or starting/stopping automation, release all controls before using the gamepad again. Use the keyboard or gamepad one at a time: their inputs replace each other's state rather than combining.

## Button mapping

| Control / position | Nintendo control | Xbox example | PlayStation example |
| --- | --- | --- | --- |
| Bottom / South | B | A | Cross (×) |
| Right / East | A | B | Circle (○) |
| Left / West | Y | X | Square (□) |
| Top / North | X | Y | Triangle (△) |
| Shoulders | L / R | LB / RB | L1 / R1 |
| Triggers | ZL / ZR | LT / RT | L2 / R2 |
| Back / Select | Minus | View / Back | Share / Create |
| Start | Plus | Menu / Start | Options |
| Guide | Home | Xbox button | PS button |
| Miscellaneous button | Capture | Share (Xbox Series X) | Microphone (PS5) |
| D-pad | D-pad | D-pad | D-pad |
| Left / right stick click | Left / right stick click | Left / right stick click | L3 / R3 |

This program does not allow you to remap control. Use the remapping from your switch instead

Home button input might be caught by other program running on your PC, such as Steam. For using home button, you can either use keyboard input or close those programs.

Both sticks work with Pro Controller output. Left Joy-Con output uses the left stick and D-pad. Right Joy-Con output uses the right stick and face buttons.

Sticks have a 15% radial deadzone. Triggers activate above 20%.
