# Shiny Hunt - Helioptile Hunter

## Program Description

Hunt shiny Helioptile in Wild Zone 14. Helioptile only appears in Zone 14 on Clear or Sunny days. This program will skip day and night until desired weather condition is met, then go into the zone to hunt it.
Mega Dimension DLC gives a faster method for shiny hunting them via Hyperspace Wild Zones.

## Settings

**Switch Settings:**

1. Screen size: Must be 100% within the Switch settings
2. [Switch 2: All HDR options must be disabled.](../NintendoSwitch/Switch2Notes.md#switch-2-hdr-may-be-problematic)
3. [Switch 2: The profile you are using must be the 1st (left-most) profile.](../NintendoSwitch/Switch2Notes.md#resetting-a-game-moves-the-cursor-to-the-1st-user-profile)

**Program Settings:**

1. Video Resolution: 1080p or higher

**Game Settings:**

1. Text Speed: Fast


## Instructions

1. Start the program.

Program will begin by traveling to the Magenta Pokémon Center and restarting the day.
It will then sit on the bench repeatedly while looking for the perfect conditions (Clear or Sunny day). 
Once appropriate conditions are found, it will warp to Wild Zone 14 when appropriate conditions are found.

## Options

### How many cycles before stopping. 0 for never stop.

Choose how long the program should run. With 0 it will run until you stop it.

A cycle is a "day change" in game, and the number of resets on a single day depends on if the weather will change before night.

After every run inside Zone 14, the program validates if the weather still appropriate for helioptile spawns. If it is not, it will go to the Pokémon Center and reset until it finds appropriate weather (Clear or Sunny day) to continue hunting.

Since before you even hear a shiny helioptile you are going to hear hundreds of other Pokémon, the program does NOT rely on shiny sound. 

There's always the risk of, if kept running endlessly, a shiny Helioptile would be overwrite by another shiny if the 10 limit cap is reach. So it's up to you.


## Recommendation
Turn the Status Notifications on, if you have them enabled on discord. This notification takes a screenshot in a position where one of the helioptile spawn is visible, so if you are lucky you will be able to see the shiny there.
